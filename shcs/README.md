# 上海文化广场 · 抢票助手

> Tampermonkey userscript for shcstheatre.com — auto-picks adjacent seats, locks them into the cart,
> and presses "确认订购" the moment it becomes clickable. Plus ticket-restock monitoring.

一个油猴脚本，帮你在 **www.shcstheatre.com** 上：

- **选座页**：按你设定的价位/区域/张数自动挑**连座**，锁进购物车（这就是"抢到了"）；
- **结算页**：盯着「确认订购」按钮，**一变成可点就立刻按下**（这页按钮通常要等几秒才算完）；
- **演出详情页**：盯每一场的**实时余票 / 放票 / 开售**，桌面通知 + 响铃 + 一键打开选座页。

付款永远手动 —— 脚本只负责把座位占住、把流程推到付款前一步。

---

## 一、装上（3 分钟，只需做一次）

1. 浏览器装 **Tampermonkey**（Chrome / Edge / Firefox 都行）。
2. **Chrome 必做**：打开 `chrome://extensions` → Tampermonkey「详情」→ 打开「**允许用户脚本**」。
   （新版 Chrome 默认关闭，不开的话脚本会静默失效。）
3. 装脚本，二选一：
   - **最快**：油猴面板「+ 新建脚本」→ 把 `shcs.user.js` 的内容整段粘进去 → 保存。
   - **走本地服务**：在本目录执行

     ```bash
     ./build.sh serve          # 保持这个终端开着
     ```

     浏览器打开 `http://127.0.0.1:8773/shcs.user.js` → 油猴弹安装页 → 安装。
     （Chrome 不允许直接双击 `file://` 的 .user.js 安装，所以才需要这一步。）
4. 打开官网任一页面，左下角应出现面板；控制台有 `[SHCS] 已加载…`。

## 二、抢票当天（选座页）

先登录，进演出详情页 → 选场次 → 点「选座购买」进入选座页。然后：

1. 点面板 **「库存」** → 看这一场真实的价位和区域（比如 `一楼观众厅 ￥680`）。
2. 打开 `config.yaml`，把 `rules` 改成真实价位 → 执行 `./build.sh build` → 油猴里点「检查更新」→ 刷新页面。
3. 点 **「预演」**：只在控制台告诉你"会挑哪几个座"，不会下单。满意后点 **「一键抢座」**。
4. 锁到座位后（面板会打印 ✅ 和座位清单）会自动跳购物车；点页面上的「结算 Checkout」。
5. 结算页不用管按钮什么时候变亮 —— 脚本会盯着，一亮就按下「确认订购」。
6. 之后按页面提示选票种/取票方式、付款。**付款自己来。**

快捷键：`Alt+Shift+I` 库存 · `Alt+Shift+P` 预演 · `Alt+Shift+R` 抢座 · `Alt+Shift+T` 自检。

> 想全自动（连"一键抢座"都省）：把 `autoRun: true`（默认已开）。想先演练：`dryRun: true`。

## 三、余票监控（可选，开票前用）

在演出详情页：

- 点 **「查场次」** → 表格列出每场：余票 / 是否开售 / 是否支持选座 / 销售期；
- 点 **「开始监控」** → 每隔 `pollMs` 查一次，**余票从 0 变有、中途放票、开售** 时：桌面通知 + 响铃 + 标题闪；
- `autoOpen: true` 时还会自动开那一场的选座页。

## 四、配置 `config.yaml`

```yaml
# —— 抢座（选座页）——
dryRun: false           # true = 只预演，绝不下单
autoRun: true           # true = 打开选座页就自动抢
maxRetry: 3             # 座位被人抢走时，自动刷新重挑的轮数
jumpToCart: true        # 锁到后自动跳购物车
rowPreference: middle   # front 前排优先 / middle 中间排 / back 后排优先

rules:                  # 备选链：从上往下试，第一条能凑齐就锁
  - price: 680          # 真实价位（用「库存」查）
    qty: 2              # 张数
    zones: []           # 区域名片段，如 ["一楼"]；空 = 不限
  - price: 480
    qty: 2
    zones: []

# —— 结算（购物车 → 结算页）——
autoCheckout: false     # 是否自动点购物车里的「结算 Checkout」（默认关，你自己点）
autoSubmitOrder: true   # 结算页盯着「确认订购」，一可点就按
confirmPollMs: 150      # 盯按钮的间隔（毫秒）
confirmMaxWaitMs: 60000 # 最多等 60 秒
confirmMaxClicks: 2     # 最多自动按 2 次（设 1 = 绝不重复按）

# —— 余票监控（详情页）——
programId: ""           # 留空 = 从当前页面 URL 自动识别
pollMs: 20000           # 查询间隔；开票前可调到 3000
minSeats: 1             # 余票 ≥ 这个数才提醒
notify: true            # 桌面通知 + 标题闪
sound: true             # 响铃
autoOpen: false         # 放票时自动开选座页
```

**挑座规则**（写在脚本里）：先按 `zones` 顺序选区域 → 同排连座优先（按页面里真实坐标判断相邻，不是按座号 +1）→ 不够再找上下排 → 最后散座；同一条连座里越靠中间越好。

**防重复提交**：结算页最多自动按 `confirmMaxClicks` 次（默认 2），两次间隔 3 秒，且只有"页面还停在原步骤、按钮仍可点"时才补第二下。

## 五、出问题怎么办

先点面板 **「自检/复制」**，把弹出来的 JSON 发给我/维护者，里面包含 URL、场次、真实价位、可售座位、环境信息。

| 现象 | 原因 / 处理 |
| --- | --- |
| 完全没有面板、控制台没有 `[SHCS]` | 油猴没生效：确认脚本已启用 + Chrome 已开「允许用户脚本」，然后刷新 |
| 控制台报 `$ is not defined` | **这个页面自己的 jQuery 被拦了**（广告拦截/隐私设置挡了 `static-pc.shcstheatre.com`）。本脚本走接口，不受影响；但页面自己画不出座位图。给本站关掉拦截即可 |
| 提示"接口和页面都没拿到座位" | 看弹框里的诊断信息发我；通常是没登录 / 该场次还没开售 |
| 结算页没自动按「确认订购」 | 点面板 **「看按钮(诊断)」**，它会列出页面上所有可点元素 —— 把这串发我，我按真实按钮文案改 |
| 按钮 60 秒都不可点 | 页面还等着你选取票方式/观演人；先手动选完，或把那页保存给我做进一步自动化 |

## 六、文件说明

| 文件 | 作用 |
| --- | --- |
| `shcs.user.js` | **装到油猴的就是这个**（由 config.yaml + engine.js 生成） |
| `config.yaml` | 唯一需要改的文件 |
| `engine.js` | 逻辑本体（改逻辑改这里） |
| `build.mjs` | 生成脚本（内置极简 YAML 解析，**不需要 npm 装任何依赖**） |
| `build.sh` | 构建 / 起本地安装服务 |
| `probe.user.js` | 接口记录器：页面改版后录一遍接口调用，方便修 |

## 七、说明

- 脚本调用官网自己的接口、用你浏览器的登录态，等价于你手动操作；请遵守场馆购票规则，不要囤票倒票。
- **不代付**，也**不替你过滑块验证**（遇到验证码时脚本会改成"替你把座位点好"，你拖一下即可）。
- 只用 Node（构建）和 python3（本地服务，可选）；不装任何第三方库。

> **Windows 用户**：`build.cmd` 双击即可重新生成（需装 Node.js）；`build.sh` 需要在 Git Bash / WSL 里跑。
> 不想装任何东西也行 —— 油猴面板「实用工具 → 从文件导入」选 `shcs.user.js` 就能安装。
